# 🎬 KinoTrack

Веб-приложение для поиска и отслеживания фильмов, сериалов и актёров на базе **The Movie Database (TMDB) API** с персональными списками и оценками пользователей в `localStorage`.

## ✨ Основной функционал

* **Каталог и раздельный поиск:** просмотр популярных новинок и поиск по трём категориям — **Фильмы**, **Сериалы** и **Актёры**.
* **Пагинация:** подгрузка следующих страниц каталога по кнопке «Загрузить ещё» без перезагрузки страницы.
* **Детальные карточки фильмов и сериалов:** постер, режиссёр/создатели, дата выхода, жанры, длительность, бюджет, сборы, описание (с автоматическим подбором доступного языка) и актёрский состав.
* **Отзывы зрителей:** вывод комментариев из базы TMDB при их наличии.
* **Страницы актёров:** биография, дата и место рождения, а также отфильтрованная фильмография известных проектов с участием актёра.
* **Аккаунты и персонализация (`localStorage`):**
  * регистрация, вход и выход из аккаунта;
  * личный список «Сохранённое» с живым счётчиком в шапке;
  * персональная оценка фильмов и сериалов по шкале от `1` до `10`, привязанная к конкретному пользователю.
* **Адаптивный интерфейс:** тёмная тема с плавными hover-эффектами, состояниями загрузки, обработкой сетевых ошибок и заглушками для отсутствующих постеров.

## 🛠 Стек технологий

* **HTML5** — семантическая разметка SPA-интерфейса.
* **CSS3** — CSS Grid, Flexbox, CSS-переменные (`:root`), адаптивная вёрстка под мобильные устройства.
* **Vanilla JavaScript (ES6+)** — асинхронные запросы (`fetch`, `async/await`, `Promise.all`), работа с DOM и `localStorage`.
* **TMDB API (v3 / v4 Auth)** — источник данных о фильмах, сериалах, актёрах и отзывах.

## 🚀 Запуск проекта

1. Склонируйте репозиторий или скачайте архив с файлами:
   ```bash
   git clone [https://github.com/ваш-username/kinotrack.git](https://github.com/ваш-username/kinotrack.git)
   ```
2. Получите бесплатный **API Read Access Token** в настройках аккаунта на сайте [themoviedb.org](https://www.themoviedb.org/).
3. Откройте файл `script.js` и вставьте ваш токен в первую строку:
   ```javascript
   const TMDB_TOKEN = 'ВАШ_API_READ_ACCESS_TOKEN';
   ```
4. Запустите `index.html` через локальный сервер (например, расширение **Live Server** в VS Code) или откройте файл в браузере.
